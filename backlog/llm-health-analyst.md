# Off-cluster LLM cluster-health analyst

Design for an autonomous cluster-health analyst that runs off-cluster on the Mac Mini; not built. The README TODO keeps a short summary of the item and links here.

**Off-cluster LLM cluster-health analyst on the Mac Mini (MED; discussed 2026-07-26)** — an autonomous agent that runs the documented health sweep and *reasons* over the raw output the way an interactive session does ("this `BLUESTORE_SLOW_OP` is benign; a stuck CNPG failover + Ceph mgr both hitting `172.30.0.1` = one ovnkube egress break"), then notifies.

**Topology decided: off-cluster on the Mac Mini (M4 Pro, 64 GB), NOT an in-cluster CronJob** — same principle as DNS-on-the-RPi (`ansible/`): a cluster-health watchdog must not depend on the cluster being up. An in-cluster job goes silent on a total outage (can't self-report "cluster down"); the Mac-hosted agent sweeps the API via `~/.kube/config-readonly` and, if the API is unreachable, **directly reports total-down** — so it needs no separate dead-man's-switch. Shape: a **launchd job** (default every 30 min) → sweep (nodes/ArgoCD/CSVs/certs/crashloops/Ceph CR + the pod→ClusterIP & backnet probes below [the per-node probe items in the README TODO]) → pipe raw output + the **known-benign alert catalog** (`.claude/skills/cluster-health/SKILL.md`) as system prompt to **local Ollama** (`qwen3:30b` MoE or `qwen2.5:32b`, comfortable in 64 GB, ~Haiku-class for *triage*) → **Telegram** the verdict.

**Read-only, analysis-only — never remediates** (no-drain cluster; a human/frontier model does the real dig). Local LLM = free, private (cluster data never leaves the box), and no pod→LAN egress dependency (the very path that breaks in the ovnkube cascade). Honest scope: a 30B local model is fine for "benign vs real + one-line concern"; deep multi-symptom RCA still escalates to a frontier model. Version-control the script + plist + system-prompt in-repo (ansible-style off-cluster pattern).

**Needs to build:** Telegram bot token + chat ID (gitignored local env/keychain, never committed), Ollama model name, cadence; Mac prereqs = Ollama serving + model pulled + no-sleep (`pmset -a sleep 0`). Complements (doesn't replace) the shipped alert-delivery path (Mailjet email since 2026-09-07; the Watchdog dead-man's switch for the in-cluster-brownout case, shipped 2026-09-25) — this is proactive "here's my read", that is "an alert rule fired".
