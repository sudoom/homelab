# backlog

Long write-ups of work that is not built yet: design, assessment and sizing for TODO items.

- The README TODO stays the index: each item keeps a one- or two-line summary and a link to its file here.
- One file per item, named `backlog/<topic>.md`.
- When the item ships, delete its file in the same commit and move its record to the topic's blog draft.
- Same secret rules as the blog drafts: this is a public repo, so no tokens, keys or kubeconfigs.
